  2. 核心数据流：剧本 → 渲染

  用户输入剧本
      ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ Phase 1: LLM 解析 (ScriptAnalysisV2)                         │
  ├─────────────────────────────────────────────────────────────┤
  │ Input: 剧本文本                                               │
  │ LLM: DeepSeek/GPT-4 + Prompt Contract V1                    │
  │ Output: {                                                    │
  │   characters: [CharacterEntity],                            │
  │   locations: [LocationEntity],                              │
  │   props: [PropEntity],          ← 新增                       │
  │   outfits: [OutfitEntity],      ← 新增                       │
  │   beats: [Beat]                                             │
  │ }                                                            │
  │ Validation: Pydantic Schema + Repair Loop                   │
  └─────────────────────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ Phase 2: 资产注册与生成                                       │
  ├─────────────────────────────────────────────────────────────┤
  │ 2.1 创建资产记录                                             │
  │   - Asset (CHARACTER) + OutfitVariant                       │
  │   - Asset (SCENE) + SceneAnchor                             │
  │   - PropAsset (HAND_PROP / SET_DRESSING)                    │
  │   - AssetRelation (关系图谱)                                 │
  │                                                              │
  │ 2.2 生成参考图 (并行)                                        │
  │   Character → CharacterCanonical (4候选 → 1选中)            │
  │   Scene → SceneAnchor (BG + ControlMaps)                    │
  │   Prop → PropAsset.ref_image_paths (2-3候选)                │
  │   Outfit → OutfitVariant.ref_image_path                     │
  │                                                              │
  │ 2.3 提取特征                                                 │
  │   Character → FaceEmbedding (FaceID)                        │
  │   Prop → PropAsset.embedding_path (CLIP/DINOv2)             │
  └─────────────────────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ Phase 3: LLM 分镜 (StoryboardDraftV3)                        │
  ├─────────────────────────────────────────────────────────────┤
  │ Input: ScriptAnalysisV2 + 资产注册表                         │
  │ LLM: DeepSeek/GPT-4 + Prompt Contract V1                    │
  │ Output: {                                                    │
  │   panels: [PanelDraft {                                     │
  │     cast: [character_id],                                   │
  │     location: location_id,                                  │
  │     props_in_hand: [{                    ← 新增              │
  │       prop_id, character_ref, usage_type                    │
  │     }],                                                      │
  │     props_in_scene: [prop_id],           ← 新增              │
  │     outfit_refs: [{                      ← 新增              │
  │       character_id, outfit_id                               │
  │     }],                                                      │
  │     ...                                                      │
  │   }]                                                         │
  │ }                                                            │
  └─────────────────────────────────────────────────────────────┘
      ↓

      ↓
  ┌─────────────────────────────────────────────────────────────┐

  │     → ComfyUIProvider                                       │

  │     → GenImageProvider (Kling/Tongyi)                       │
  │                                                              │
  │ 5.2 ComfyUI 渲染流程                                         │
  │   - 选择 Workflow 模板 (layered_panel_v1)                    │
  │   - 填充参数:                                                │
  │     * Character Layer: FaceID + Outfit Prompt               │
  │     * Prop Layer: Mask + Inpaint                            │
  │     * BG Layer: Scene Anchor + ControlNet                   │
  │   - 上传资产到 ComfyUI                                       │
  │   - 提交任务                                                 │
  │                                                              │
  │ 5.3 GenImage 渲染流程                                        │
  │   - 构建统一 Prompt (Character + Outfit + Props + Scene)    │
  │   - 调用 API (Kling/Tongyi/Runway)                          │
  │   - 等待结果                                                 │
  └─────────────────────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ Phase 6: 质量评估 (EnhancedQA)                               │
  ├─────────────────────────────────────────────────────────────┤
  │ 6.1 多维度评分 (并行)                                        │
  │   - story_structure: 剧情结构完整性                          │
  │   - visual_quality: 图像质量 (清晰度/噪点)                   │
  │   - character_consistency: 角色一致性 (FaceID相似度)         │
  │   - prop_presence: 物品完整性 (检测是否存在)    ← 新增       │
  │   - text_readability: 文字可读性                            │
  │   - composition: 构图质量                                    │
  │                                                              │
  │ 6.2 生成 QA Report                                          │
  │   {                                                          │
  │     overall_score: 0.85,                                    │
  │     dimension_scores: {...},                                │
  │     issues: [{severity, dimension, description}],           │
  │     suggestions: [...]                                      │
  │   }                                                          │
  └─────────────────────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ Phase 7: 智能修复 (Auto Repair)                              │
  ├─────────────────────────────────────────────────────────────┤
  │ IF overall_score < threshold AND retry_count < max:         │
  │                                                              │
  │ 7.1 分析问题                                                 │
  │   - 角色崩坏 → ADJUST_PARAMS (seed, cfg)                     │
  │   - 物品缺失 → INPAINT_FIX (局部重绘)        ← 新增          │
  │   - 质量不佳 → SWITCH_PROVIDER (切换提供者)                  │
  │   - 持续失败 → INCREASE_TIER (升级到 hero)                   │
  │                                                              │
  │ 7.2 执行修复                                                 │
  │   - 应用修复策略                                             │
  │   - 重新渲染                                                 │
  │   - 记录修复历史                                             │
  │                                                              │
  │ 7.3 预算控制                                                 │
  │   - 检查 budget_used < budget_limit                         │
  │   - 超预算 → 降级策略或停止                                  │
  └─────────────────────────────────────────────────────────────┘
      ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ Phase 8: 气泡渲染与导出                                       │
  ├─────────────────────────────────────────────────────────────┤
  │ 8.1 气泡排版                                                 │
  │   - 根据 dialogue_lines 生成气泡                             │
  │   - SVG 渲染 (Konva)                                         │
  │   - 自动避让角色/物品                                        │
  │                                                              │
  │ 8.2 合成导出                                                 │
  │   - 合并图层 (BG + Character + Prop + Bubble)               │
  │   - 导出长条漫 PNG                                           │
  │   - 可选: 导出视差微动 MP4                                   │
  └─────────────────────────────────────────────────────────────┘
      ↓
  完成 ✓
